# Shape Optimization of Stokes–Darcy Coupled Systems

This repository contains the FreeFEM++ implementations accompanying the manuscript **“Shape optimization of Stokes–Darcy coupled systems in free-flow and porous media.”**

The method minimizes energy dissipation in a free-flow region coupled to a porous medium through the Beavers–Joseph–Saffman (BJS) interface conditions. Distributed and interface-type Eulerian derivatives are combined with an adjoint-based shape gradient algorithm, finite element discretization, and a moving body-fitted mesh. The examples cover single and multiple interfaces, diffuser design, and embedded vessel–tissue configurations in two and three dimensions.

This README describes the revised manuscript and the supplied code package. Numerical values below are manuscript-reported reference results, not results generated by running the scripts during preparation of this README.

## 2. Running the examples

Use a FreeFEM++ installation supporting the elements and mesh operations used in the scripts. Depending on the example, the scripts load `Curvature`, `iovtk`, `gmsh`, and `medit`. A tested FreeFEM++ version number is not specified in the supplied materials.

Run each script from its own directory so that relative mesh paths resolve correctly. For example, starting from the package root:

```sh
cd "Sec 4.1：Single-interface around a porous region/case4.1.1"
FreeFem++ "EX1_case4.1.1_Semi_Ellipse.edp"
```

For the 3D diffuser, starting again from the package root:

```sh
cd "Sec 4.3：Diffuser model/3D"
FreeFem++ "EX3_3D_diffusion_kp=0.01.edp"
```

Keep `diffusion.msh` or `bloodmesh.msh` beside the corresponding 3D script. The 2D scripts construct their meshes internally. The 3D Taylor-test filename contains a space between `Taylor` and `_test_3D.edp`; quote it exactly.

Use a fresh copy of the case directory for each parameter run. Several scripts write generic filenames such as `objective.txt` and `volerr.txt`, and some histories are opened in append mode. Reusing a directory can mix histories from different runs or overwrite field outputs.

## 3. Model and numerical method

The free-flow region $\Omega_f$ satisfies the Stokes equations, and the porous region $\Omega_p$ satisfies the Darcy equation. Their common interface enforces normal-flux continuity, normal-stress balance, and the BJS slip condition.

The objective is the free-flow viscous dissipation

$$
\mathcal J(\Omega_f)=2\mu_f\int_{\Omega_f}|\mathcal E(\mathbf u_f)|^2\,\mathrm dx,
\qquad
\mathcal E(\mathbf u_f)=\tfrac12(\nabla\mathbf u_f+\nabla\mathbf u_f^\top).
$$

The state and adjoint systems use MINI velocity–pressure elements (`P1b`/`P1`) in the fluid and continuous `P1` elements for the Darcy hydraulic head. The mesh deformation is represented using continuous `P1` fields. The 2D optimization examples use the distributed derivative; the 3D examples use the interface derivative.

Unless otherwise stated, $g=1$ and body forces vanish. Inlet velocities are specified by case, the fluid outlet has zero natural traction, prescribed porous Dirichlet boundaries have $\phi=0$, and the remaining porous boundaries have zero flux.

For isotropic conductivity $\mathbf K=k_p\mathbf I$, the effective BJS coefficient is

$$
\gamma=\alpha\sqrt{\mu_f g/k_p}.
$$

The fundamental BJS constant $\alpha$ is fixed within each parameter study. Recompute $\gamma$ whenever $k_p$ or $\mu_f$ changes.

### Volume constraint and iteration

The target fluid volume $V_0$ is imposed through

$$
\mathbb G(\Omega_f,l)=\mathcal J(\Omega_f)+l c(\Omega_f)
+\tfrac12\beta_1c(\Omega_f)^2,
\qquad c(\Omega_f)=|\Omega_f|-V_0.
$$

Shape differentiation holds $l$ fixed. The multiplier update is

$$
l_{n+1}=l_n+\beta_2c_n,
\qquad c_n=|\Omega_{f,n}^h|-V_0.
$$

Thus the update uses the volume residual before the next deformation. It does not enforce exact volume feasibility at every iteration. Each optimization loop solves the state and adjoint systems, computes a deformation direction, selects a step, and updates the interface and multiplier according to the case-specific acceptance rules.

Mesh connectivity is fixed throughout. The 2D codes use `checkmovemesh` with step halving to avoid triangle inversion; the 3D optimization codes use conservative fixed steps. No remeshing or topology changes are performed.

### Stopping and interpretation of histories

The relative objective-change test is

$$
\frac{|\mathbb G_n-\mathbb G_{n-1}|}
{\max\{|\mathbb G_{n-1}|,10^{-30}\}}<\epsilon_{\mathrm{obj}}.
$$

Recorded values use the current multiplier, so successive changes combine shape and multiplier effects. This is a termination test, not a certificate of constrained stationarity or a fixed-multiplier descent test. Report the original dissipation and relative volume error $|c_n|/V_0$ separately.

In Case 4.1.2 and the 2D diffuser runs, meeting the test triggers termination after one further deformation. Otherwise, the basic algorithm terminates before another deformation. In 3D the test is enabled after the first ten loop evaluations; the reported diffuser and vessel–tissue runs reach their limits of 400 and 450 iterations. Example 2 has additional acceptance and failure rules described below.

Final quantities are recomputed on the returned domain with its stored multiplier and may differ from the last history entries. A reported loop index need not equal the number of accepted deformations.

### 4.1. Single interface around a porous region

**Case 4.1.1 — Semi-elliptical riverbed.** The domain is $[0,2]\times[0,1]$, with initial porous region

$$
\Omega_p=\{(x,y):(x-1)^2/0.5^2+y^2/0.4^2\leq1,\ y\geq0\}.
$$

The revised inlet profile is compatible with the no-slip walls at both inlet corners:

$$
u_{\mathrm{in}}(y)=\frac{0.2}{1-\delta}
S(y/\delta)S((1-y)/\delta),\qquad\delta=0.1,
$$

where

$$
S(s)=
0,s\leq0,
10s^3-15s^4+6s^5,0<s<1,
1,s\geq1.
$$

The inlet velocity is $(u_{\mathrm{in}},0)^\top$, and the total inflow remains $0.2$. The transition length is independent of mesh size. The optimization mesh has 6246 fluid and 1130 porous triangles. The manuscript reports dissipation decreasing from $2.52626\times10^{-4}$ to $1.42063\times10^{-4}$, a reduction of $43.77\%$, with final relative volume error $6.85\times10^{-4}$.

The `mesh_check_n10`, `mesh_check_n20`, and `mesh_check_n40` scripts assess the initial-geometry dissipation using the same inlet profile. Here $n$ scales the boundary subdivisions in `buildmesh`. Reported values are $2.53327\times10^{-4}$, $2.52626\times10^{-4}$, and $2.52151\times10^{-4}$; the last refinement changes the value by about $0.19\%$. The optimization script also reports fluid mass-conservation and interface-condition residuals as diagnostics of the discrete solution.

**Case 4.1.2 — Curved interface.** The inlet is $\{0\}\times[0.35,1]$, with

$$
u_{\mathrm{in}}(y)=\frac{13}{60}S((1-y)/0.1).
$$

This one-sided transition vanishes at the top-wall junction and preserves continuous inflow $0.13$; the reported discrete flux is $0.129997$. The mesh has 2633 fluid and 1277 porous triangles. A curvature contribution with coefficient $18$ is included only in the deformation-direction functional. It is excluded from the monitored objective and does not itself guarantee descent or stationarity.

The manuscript reports 169 iterations, dissipation decreasing from $0.888296$ to $0.430954$ ($51.49\%$), and final relative volume error $4.93\times10^{-3}$. The separate 2D Taylor test is described in Section 5 below.

### 4.2. Multiple interfaces in an L-shaped configuration

The domain is $[0,1]^2$, with 2444 fluid and 5654 porous triangles and inlet velocity $(1.2,0)^\top$. The distributed derivative supports the nonsmooth initial geometry without requiring the additional regularity assumed for the interface expression.

The direction uses the example-specific bilinear form in the manuscript and a curvature smoothing coefficient $\alpha_\Gamma=30$. Curvature smoothing affects only the direction; it is excluded from objective evaluations and stopping tests.

The revised implementation requires a negative directional derivative of the augmented objective and a mesh-admissible Armijo step, with initial trial step $5\times10^{-4}$, Armijo parameter $10^{-4}$, halving factor $0.5$, and minimum step $10^{-10}$. The state is solved again on each trial mesh while the multiplier remains fixed. If the smoothed direction fails, the mesh is restored and subsequent directions are computed without curvature smoothing. If that search also fails above the minimum step, the last accepted mesh is returned without a multiplier update. The multiplier is updated only after acceptance, using the pre-deformation volume residual.

The reported run accepts 295 deformations. The last accepted loop index is 296; evaluation 297 ends without an admissible Armijo step. Termination is due to step-search failure, not the objective-change tolerance. The returned dissipation is $0.259745$ versus $3.69062$ initially, and the relative volume error is $5.96\times10^{-3}$. Accepted steps decrease the fixed-multiplier augmented objective; this does not imply monotonicity across multiplier updates.

### 4.3. Diffuser model

Both dimensions study $k_p=0.01$ and $0.005$, with viscosity, target volume, optimization parameters, and fundamental BJS constant fixed within each dimension.

- **2D:** inlet velocity $(0.1,0)^\top$; 986 fluid and 604 porous triangles. The reported relative volume errors are $9.55\times10^{-4}$ and $3.66\times10^{-3}$ for the two permeability values.
- **3D:** inlet velocity $(0,1,0)^\top$; 4192 fluid and 7215 porous tetrahedra in `diffusion.msh`. Both reported runs reach 400 iterations, with relative volume errors $5.04\times10^{-3}$ and $1.21\times10^{-3}$.

The supplied scripts default to $k_p=0.01$. Change the permeability for the second run and retain the BJS recomputation.

### 4.4. Embedded vessel–tissue model

The free-flow channel is embedded in a surrounding porous region, providing a continuum-scale model motivated by vessel–tissue coupling.

- **2D:** inlet velocity $(1,0)^\top$; 1430 fluid and 5078 porous triangles. The viscosity study uses $\mu_f=1,0.1,0.01$ and reports relative volume errors $3.48\times10^{-4}$, $4.42\times10^{-5}$, and $3.54\times10^{-4}$. The supplied script defaults to $\mu_f=1$.
- **3D:** inlet velocity $(0,1.5,0)^\top$; 2262 fluid and 78142 porous tetrahedra in `bloodmesh.msh`. The reported run reaches 450 iterations and ends with relative volume error $6.12\times10^{-3}$.

## 5. Derivative verification

Taylor tests hold one prescribed smooth deformation field fixed, normalize its largest absolute nodal component, and set it to zero on the fixed outer boundary. Both subdomains are moved by the same mapping, and the state problem is solved again at each perturbation size. The tested objective is $\mathcal J$, excluding the volume constraint and heuristic curvature smoothing.

The measured finite-difference error is

$$
e(\delta)=\left|\frac{\mathcal J((\mathrm{Id}+\delta\mathbf d^h)\Omega_f^h)
-\mathcal J(\Omega_f^h)}{\delta}
-\mathrm d\mathcal J(\Omega_f^h;\mathbf d^h)\right|.
$$

The manuscript reports approximately first-order decay of this quotient error over the tested ranges.

| Test | Script | Derivative | Perturbation sizes |
|---|---|---|---|
| 2D, Case 4.1.2 | `Taylor_test_2D.edp` | Distributed and interface | $0.2,0.1,0.05,0.025$ |
| 3D, Example 4 | `Taylor _test_3D.edp` | Interface | $0.04,0.02,0.01,0.005$ |

The 2D test uses the revised Case 4.1.2 inlet and physical parameters, on a refined mesh with 10421 fluid and 5103 porous elements.

The 3D test uses $\mu_f=0.01$, $k_p=10^{-4}$, $g=1$, and $\alpha=0.1$. Its BJS constant differs from the 3D optimization value $\alpha=0.01$.

**Discrete implementation distinction:** the 3D optimization scripts project $G_3$ and the vector field defining $G_4$ into continuous surface `P1` spaces before computing surface divergences. The supplied 3D Taylor script uses directly expanded facewise expressions for those terms. It tests the interface derivative form, but does not verify exactly the same discrete realization used by the optimization scripts. Fixed spatial and geometric errors can also limit the perturbation range in which first-order decay is observed.

## 6. Outputs and reproducibility

Depending on the script, outputs include objective and volume-error histories, initial/final or intermediate meshes, velocity and pressure/head fields in `.dat` files, and quantitative summaries such as `quantitative.txt` or `quantitative3D.txt`. The 3D Taylor test writes `Taylor_test_3D_results.txt` with perturbation sizes, errors, and observed orders. Consult each script's output statements for exact filenames and write frequency.

For comparisons with the manuscript, retain the inlet profile, physical parameters, BJS recomputation, mesh, direction construction, and stopping convention. Compare recomputed final values with the final-value tables, rather than assuming they equal the last history row. The reported experiments used an Intel Core i5-12500H at 2.50 GHz with 16 GB RAM; timings depend on the execution environment.

The method evolves existing interfaces with fixed mesh connectivity. It does not perform topology optimization or establish constrained stationarity merely by reaching an iteration limit or objective-change tolerance.
